# TGZJDV's Chat（TGZJDV的聊天框）

一款改进 Minecraft 聊天框的 **Fabric 客户端模组**，将聊天框重构为**聊天软件风格**的侧边栏界面。

## ✨ 功能特性

### 🎨 聊天界面
- **聊天软件样式双模式**：未打开聊天时左下角小块（自动隐藏）；按 T 打开后左侧完整面板
- **消息气泡**：自己（右侧绿色）、别人（左侧白色）、系统消息（居中）
- **玩家头像**：皮肤头像显示（支持服务器皮肤插件）
- **玩家名**：气泡上方彩色显示
- **时间戳**：气泡旁显示（自己左、别人右）
- **右键菜单**：头像/消息/图片右键，支持回复、复制、tpa/tpahere 等

### 🖼️ 图片发送
- **一键发图**：输入框旁图片按钮 → 文件管理器选择 → 上传图床 → 发送
- **文件管理器**：驱动器/功能文件夹侧边栏、地址栏、后退/前进、滚动条
- **图片查看**：点击放大、滚轮缩放、左键拖动、右键复制
- **安全模式**：链接打断绕过服务器链接检测
- **使用协议**：首次使用需同意上传协议

### 💬 聊天增强
- **回复功能**：@玩家 + 引用原消息
- **私聊频道**：频道切换、未读提示
- **命令快捷**：登录/死亡点/返回/回家/tpa/tpahere 自定义命令
- **链接点击**：字符级精确点击、悬停提示
- **滚动条**：消息列表滚动、点击跳转、拖动

### 🛠️ 兼容性
- **Chat Pro**：兼容其回复消息和图片消息格式
- **Chat Heads**：兼容 `<[名 head]名>` 格式
- **多版本**：支持 Minecraft 26.1 / 26.1.1 / 26.1.2 / 26.2

## 📥 安装

1. 安装 [Fabric Loader](https://fabricmc.net/use/) 和 [Fabric API](https://modrinth.com/mod/fabric-api)
2. 下载本模组（根据你的 Minecraft 版本选择）
3. 放入 `.minecraft/mods/` 文件夹

| 文件名 | 适用版本 |
|--------|---------|
| `tgzjdvchat-mc26.1-1.4.0.jar` | Minecraft 26.1 |
| `tgzjdvchat-mc26.1.1-1.4.0.jar` | Minecraft 26.1.1 |
| `tgzjdvchat-mc26.1.2-1.4.0.jar` | Minecraft 26.1.2 |
| `tgzjdvchat-mc26.2-1.4.0.jar` | Minecraft 26.2 |

## 🎮 使用说明

- **T**：打开/关闭聊天
- **图片按钮**（输入框旁）：发送图片
- **设置按钮**（标题栏）：打开设置
- **右键头像/消息/图片**：打开右键菜单
- **Mod Menu**：模组菜单中可进入设置、查看主页
